# Banana Hacks 2026

Site: https://www.bananahacks.tech (FAQ, rules, prizes pages). Checked on Oct 10, 2026.

## Key facts

- Free, fully online, Oct 9 to 12, 2026. Discord for community, Zoom for live sessions.
- Theme: generative AI and image AI. The theme criterion asks that image AI is **central**, not cosmetic. For ChartVoice, reading the chart image (DePlot) is the core, so say that clearly.
- Eligibility (FAQ): students aged 14 to 24, currently enrolled. Make sure the whole team qualifies.
- Teams of 1 to 4. One team per person.
- Pretrained models, public APIs and open-source libraries are allowed, **but must be credited**, including in the README. Name every AI tool you used when you submit.
- All work must be done during the hacking window. Commit timestamps are checked. Work started before the opening ceremony is not eligible.

## Submission checklist

- [x] Project name (ChartVoice, checked Oct 12: no other product uses it)
- [ ] One-paragraph description, and a write-up of **500 words or less** (what you built and why)
- [ ] Public GitHub repo link (check it opens while logged out)
- [ ] Demo video, **3 minutes or less** (aim for 2:50), public link that works
- [ ] Working demo: live URL or the recorded video
- [x] README credits: DePlot (`google/deplot`, Apache-2.0), Groq models used, ChartQA (if used for eval, check its license), Chart.js, Atkinson Hyperlegible font (SIL OFL), React, Vite, FastAPI, any other library

## Judging

Five criteria, each scored 1 to 5, equal weight:

1. **Technical execution and difficulty.** Real engineering, thoughtful model choice, non-trivial integration. Thin API wrappers score lower.
2. **Innovation and creativity.** Fresh angle. Generic clones score lower.
3. **Use of the image AI theme.** Image AI must be central. If you could remove it without breaking the core, you score lower.
4. **Impact and usefulness.** Real problem, clear user, could be used beyond the weekend.
5. **Design, presentation and demo.** Polished UI, and a video and write-up that clearly explain the problem and how it works.

Special awards (everyone is considered automatically): Best Creative Tool, Best Fine-tune, Most Surprising Output, People's Choice (participant vote on demo day).

Prizes: $500 cash for the top project, plus CodeCrafters memberships, Interview Cake licenses and .xyz domains.
